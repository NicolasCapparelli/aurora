# @aurora/core

The portable Aurora core in TypeScript: colors, typed tokens, contracts and the
generated foundation, themes and variants, textures (all 13 value types, aliases
and validation), the selection runtime, contrast diagnostics, the pinned
seed-based generator (all nine schemes, `aurora-*-v1-mcu-0.11.1`), the DTCG colour
and texture codecs, and theme and texture recipes.

It has no DOM, React or Node dependency and no side effects. It is private (`"private": true`) and not published to npm.

The behavior is defined by `spec/` and checked against every file in
`spec/fixtures` by `test/portable.test.ts`. Error classes carry the same
categories as the Dart core (`validation`, `format`, `argument`, `state`);
messages may differ. Accessors in `src/foundation.ts`, `src/starters.ts`,
`src/materialRoles.ts` and `src/textureFoundation.ts` are generated by
`tools/generate_foundation.py`; do not edit them by hand.
